## 小游戏的用户、品类、变现模式的多元精细化发展

### 2017～2020年 生态和基建逐步完善

| 分类 | 内容 |
| --- | --- |
| 品类 | 低门槛超休闲→轻度休闲品类拓宽——益智、快速反应、IO等 |
| 用户 | 男女比例均衡，中年居多；低线城市用户占比高 |
| 变现 | 广告变现模式逐渐成熟，2018开始提供广告组件，支持广告变现 |
| 技术 | 合作生态开放，产品数量突破；包体规模、本地缓存上限提升；研发工具更加完善 |

### 2021～2022年 高速发展生态繁荣

| 分类 | 内容 |
| --- | --- |
| 品类 | 题材创新，玩法变重，开始精品化——如沉浸体验和悬疑小游戏 题材更加泛化，玩法向中重度发展，模拟、动作、射击、塔防突出 |
| 用户 | 男女比例均衡，更多年轻玩家进入 |
| 变现 | 玩法丰富，用户规模和ARPU双重驱动，IAP小游戏市场规模迅速发展 |
| 技术 | 明确小游戏实名制；抖音买量支持跳转；投放和研发工具更加完善 |

### 2023～至今 行业规模突破持续高质量发展

| 分类 | 内容 |
| --- | --- |
| 品类 | 精品化、中度休闲占比提升——如塔防、中度消除、模拟经营 玩法向中重度发展，模拟、动作、射击、塔防突出 |
| 用户 | 男女比例均衡，城市线级分布更均匀；中青年男性占比更高，游戏付费能力强 |
| 变现 | 商业化模式突破，实现规模快速提升，混变成为趋势 |
| 技术 | 推出各项小游戏扶持计划；升级小游戏扶持计划 |

## IAP 小游戏重点品类消耗趋势

传统重度类（如RPG、SLG、放置卡牌）均保持小幅度增长；经典休闲类中二合三消品类玩法加深，占比增长明显，最新季度占比达到6%+；融合玩法、塔防类占比趋稳，融合ike类型占比萎靡；模拟经营品类小幅下滑。

**2025Q1重点品类消耗占比：** RPG（传奇/仙侠等）、融合like、塔防三类消耗占比最高，合计接近60%。

**重点品类产品数量趋势：** 和消耗趋势基本一致，RPG稳定增长，模拟经营&融合lke增速放缓。
