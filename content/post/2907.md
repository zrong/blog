## 1. 小游戏大出海

### 为什要在微信平台做 Puzzle 类小游戏？

1. Puzzle 小游戏的生命周期长且留存率高，这为游戏的持续发展提供了坚实的基础。
2. 微信小游戏在国内外榜单上的表现稳定，尤其海外榜单新产品多源自国内，显示出其市场潜力巨大。
3. 微信小游戏的成功率理论上高于海外榜单，出海成功后收入可实现多倍增长，具有显著的经济价值。

以下五个海外小游戏，均来源于微信小游戏，在榜单上的成绩表现良好，证明了微信小游戏的国际竞争力。

 ![dcfdbe4ae9e26c59c0e824c48f54fe76.png](/uploads/2025/puzzle-hit-pipeline-8.png)

### 为什么微信小游戏优先？

1. 微信小游戏优先策略基于高测试效率，如一天迭代一两个版本，适应快速变化的市场。
2. 微信小游戏处于创新红利期，正确的立项与优秀执行可确保高成功率。
3. 国内成功的小游戏在海外同样具有较高成功率，降低海外发行风险。
4. 海外游戏发行周期长，可能需4至6个月或更久，而小游戏能显著缩短这一过程。
5. 通过举办 Puzzle 训练营直播，聚焦立项流程与方法，提升项目成功率。

### Puzzle 高级训练营是什么？

1. 分享已验证的核心玩法拆解，以及 SCAMPER 模型在原型创新设计中的应用方法，旨在提升开发者的创新设计能力。
2. 探讨 Level Based 难度曲线的平衡策略，确保游戏体验既具挑战性又不失乐趣，满足不同玩家需求。
3. 定期举办训练营，包括立项推荐和市场趋势洞察分享，为开发者提供持续学习与成长的平台。
4. 不定期分享成功案例，通过实际例子激发开发者灵感，促进经验交流与知识共享。
5. 构建国内开发者生态，助力开发者在海外市场取得更好成绩，强调了训练营对提升中国开发者国际竞争力的重要性。

Puzzle 高级训练营的愿景是：构建国内开发者生态。

## 2. 爆款公式

### 爆款的数据目标


**小游戏**

- D0 时长 1200秒
- D1 留存 20%，时长=2400+秒
- D7 留存 8%

**APP**

- D7 留存 20+%
- D30 留存 10+%
- 时长 3000秒

爆款公式的三个维度：**次留率、游戏时长、长期留存率。** 实践证明，设定的高指标并非遥不可及，通过优化用户体验、增加游戏深度与社交互动等手段，有效提升三个维度的指标，实现爆款产品的打造。

### 爆款公式=新颖性+强反馈+深度

![df5cee9163e0720a464a447e1105d936.png](/uploads/2025/puzzle-hit-pipeline-9.png)

1. 新颖性是游戏吸引玩家的关键，通过似曾相识但别具新意的玩法升级，如Carjam在经典挪车玩法上加入 Stack 收集和 Slots bar 机制，提升了游戏体验和变现能力。
2. 强反馈机制是驱动玩家推进关卡的核心，如 Hexa Sort 的翻转堆叠、拆解过程的扭曲感及倒水游戏的倒水效果，这些直观且满足的反馈增强了玩家的参与度和满意度。
3. 游戏深度体现在核心机制的策略选择和关卡多样性上，如 Carjam的路径规划、hex shot的位置选择和螺丝的360度旋转观察，这些元素共同促进了游戏的长期留存率。
4. 引入新机制和玩法可以创造深度，使玩家制定解谜策略，如车库机制的出现要求玩家优先解决特定问题，增加了观察目标的多样性和策略性，提升了游戏的吸引力。
5. 优化关卡设计和反馈节奏，遵循输入简单、2-3秒内可产生选择的原则，以及一次输入多次输出的惊喜反馈，是提升休闲游戏体验和玩家留存率的有效策略。

### 深度：内容

![f2a2275cf4d0cf1c79605ff665acfc78.png](/uploads/2025/puzzle-hit-pipeline-10.png)

1. 螺丝消除通过提供内容深度，如每个关卡的独特设计，保持玩家新鲜感，从而实现高长期留存率，证明了内容创新的重要性。
2. 烤串烧选择生活化主题，结合内容收集深度，成功吸引玩家，表明主题与内容深度结合能有效提升游戏的长期吸引力。
3. 两个案例均未引入复杂游戏机制，而是通过内容的丰富性和新鲜感，实现了用户的长期留存，强调了内容设计在游戏中的关键作用。
4. 内容深度的提升不仅限于关卡设计，还可以通过主题选择和收集元素等方式实现，为游戏设计提供了多样化的思路。
5. 内容深度是提升游戏长期留存率的有效策略，对游戏开发者具有重要启示。

### 深度：随机性

1. 随机性在关卡设计中的作用及其对玩家体验的影响，包括提供意外惊喜感和增强变现能力，但过多随机性会导致玩家缺乏掌控感，增加关卡流失率。
2. 静态关卡与动态关卡的区别，静态关卡能给予玩家进步感和成就感，适合较短的游戏时长，而动态关卡每次体验不同，适合较长的游戏时长。
3. 关卡设计时，根据目标游戏时长选择合适的关卡类型，两到三分钟的关卡建议采用静态设计，而五到七分钟的关卡建议采用动态设计。
4. Rolic 的产品大部分采用静态观察，静态关卡的设计能增强玩家的成就感和解谜感，适合短期游戏体验。
5. 讨论立项方法的引入，为关卡设计和游戏开发提供了一个新的讨论方向，强调了设计前规划的重要性。

## 3. 立项方法

### 立项核心三要素

![1d1db01725cf2ade06a48126ae800a2d.png](/uploads/2025/puzzle-hit-pipeline-11.png)

### 从新概念开始

1. 从日常生活、社交媒体、测试中的热原型或过往成功游戏中寻找新玩具或主题作为灵感来源，进行信息输入。
2. 挖掘新玩具可能带来的有趣体验，将其游戏化，以增强玩家的参与感和兴趣。
3. 选择成熟的游戏机制，结合新玩具特征，进行微创新，构建已验证的体验框架。

![731f75188bd6372e190a64682d77c4ed.png](/uploads/2025/puzzle-hit-pipeline-12.png)

### 从已验证的核心玩法开始

![02028a11708dd90bea38da5d0d885e68.png](/uploads/2025/puzzle-hit-pipeline-13.png)

从毛线消除等小游戏产品中获得灵感，探索类似毛线的其他玩具，如捏泡泡、撕胶带等，提供 ASMR 体验 。

通过新玩具和成熟游戏机制的结合，创新游戏体验，提升游戏吸引力和玩家满意度。

### 不要换皮

1. 不要进行简单的换皮，因为这不会带来新的体验或竞争优势，尤其是在竞争激烈的市场环境中。
2. 换主题时，应考虑新主题的人群画像变化以及与原主题人群的重复度，以减少市场重叠。
3. 放玩具是提升游戏新鲜感和反馈的有效方式，通过改变核心体验来吸引玩家，成功率更高。
4. 机制的融合创新是提升游戏深度和反馈感的关键，如通过融合反馈感强的玩具来改进现有机制。
5. 玩具定义为玩家直接控制的对象，与之交互是游戏体验的核心，而非仅改变主题或材质的换皮行为。

### 立项检查清单

![83ca4a48ef3cf1fb2b2caa3ae19a8880.png](/uploads/2025/puzzle-hit-pipeline-14.png)

1. 验证新创意的可行性，首先检查其核心差异化卖点，确保在市场中具备竞争优势，这是成功的关键。
2. 考虑游戏主题的受众范围，避免选择小众主题，以防用户基础有限，影响买量成本和游戏规模。
3. 深度分析游戏机制，包括关卡设计的多样性和随机性，以及游戏内容的丰富度，这些因素对长期用户留存至关重要。
4. 确保游戏机制中包含强有力的失败条件，以增加游戏的挑战性和变现潜力，如空间管理的失败条件优于时间或步数限制。
5. 在创意融合阶段，保留核心体验同时创新机制或主题，探索如「倒水」体验结合新机制或不同主题的变种可能性，以激发新市场。

## 4. 原型阶段：最佳实践

### V1版本清单

![eba2b81c3147e4c601722eba842ff085.png](/uploads/2025/puzzle-hit-pipeline-15.png)

1. 确认核心反馈感觉满意是进入其他游戏内容制作的前提，否则建议砍掉项目并寻找新概念，以确保游戏方向正确。
2. 制作1小时游戏内容，约20到30个关卡，足以测试核心玩法的潜力和预测留存率，减少资源浪费。
3. 游戏仅需包含三种最基础机制，核心玩法的创新体验和反馈质量决定留存率和游戏时长，而非内容数量。
4. 开发者常误以为内容量决定留存率和游戏时长，实际上核心玩法的体验感才是关键，需重视。
5. 通过少量关卡测试核心玩法，可有效评估游戏未来潜力，避免过度开发导致的资源浪费和市场风险。

### 核心体验清单

![70bca0861475cc6ce34cd9bf5942ed8b.png](/uploads/2025/puzzle-hit-pipeline-16.png)

1. 确定游戏的核心体验，明确关键点以提高效率和成功率。
2. 实现核心体验的关键逻辑，如控制游戏节奏感和关卡难度，确保玩家体验。
3. 专注于机制核心反馈和动画表现的打磨，提升玩家游戏时长和参与度。
4. 美术设计上，强调核心玩法的色彩对比和质感，移除无关元素，精简视觉效果。
5. 学习和借鉴成功案例，如 magic sort，其色彩对比、饱和度和材质质感的优秀表现。

### 5 个基础标准关卡

![aa840aa9b2b25f6dc6ab9d8eb1368411.png](/uploads/2025/puzzle-hit-pipeline-17.png)

1. 制作五个基础关卡，包括一个普通关卡、两个困难关卡和两个超级困难关卡，以确认关卡节奏感、难度曲线和卡点机制，确保质量可控。
2. 明确每个关卡的设计目标和测试目标，避免关卡设计过于简单或复杂，确保关卡设计合理。
3. 在确认五个基础关卡自我满意后，可将这五个关卡复制扩展成25个关卡，以提高游戏的丰富性和可玩性。
4. 考虑关卡设计和玩家体验之间的循环节奏，确保游戏的整体体验和玩家的参与度。5. 通过基础关卡的制作和体验，为后续关卡设计和游戏优化提供参考和指导，确保游戏品质的持续提升。

### 25 个内容关卡

![7682f23586ce6a8d0b10d57a9a0568fb.png](/uploads/2025/puzzle-hit-pipeline-18.png)

1. 将游戏设计为每五个关卡一个节奏循环，共25个关卡，确保玩家经历五次完整的游戏循环，以测试游戏的节奏和平衡性。
2. 在不同的关卡范围内测试不同的难度曲线，确保游戏的挑战性和趣味性，同时满足不同玩家的需求。
3. 虽然当前版本只制作25个关卡，但需提前规划后续关卡的深度和内容，为未来的游戏扩展和更新奠定基础。
4. 关注关卡设计的创新性和多样性，避免玩家在重复游戏中感到厌倦，提升游戏的可玩性和吸引力。
5. 在游戏开发初期就考虑玩家反馈和测试数据的收集机制，以便于后续版本的优化和调整，确保游戏质量的持续提升。
