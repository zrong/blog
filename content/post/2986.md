## Chatbox 配置

今天早上发布的文章 [DeepSeek 服务器繁忙？这里是解决方案 | 胡扯AI](:/034cf183fe3149039c38929e59500c37) 介绍了 Chatbox 的使用方法。

Chatbox 没有提供腾讯 API 支持，但我们可以采用 OpenAI 兼容 API 的方式进行配置。

以下是腾讯云提供的 OpenAI 兼容接口文档。

![OpenAI接口配置](/uploads/2025/tencent-cloud-free-deepseek-r1-8.png)

https://cloud.tencent.com/document/product/1772/115969

根据文档中的描述，我们对 Chatbox 进行配置：

1. 添加一个自定义模型提供方 Tencent；
2. 按照文档中的设置，填写 API 域名和 API 路径；
3. 填写上一步生成的 API 密钥；
4. 模型填写 `deepseek-r1`；
5. 上下文消息数量上限填写 64（不限制）。

![Chatbox 配置](/uploads/2025/tencent-cloud-free-deepseek-r1-9.png)
