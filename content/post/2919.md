## 好像应该抄订单模式

从这三个水排序代表性玩法产品的排名趋势看，只有 **精明的开局** 在持续霸榜，这似乎说明其采用的 **订单模式** 优于标准的水排序模式。

所以我们就抄 **订单模式的水排序** ！

曾老师打听了一下，已经有十几个团队在抄这个玩法了。在这么卷的情况下，抄个一模一样的可能来不及暴富就已经暴雷了，得换一个创新的思路。

让我们打开常用的 AI 工具头脑风暴一下：

Q： **为啥订单模式更靠谱？**  
A：可能是订单玩法让局内目标感更强。

Q： **有没有其它设计方式，目标感能比订单模式更强？**  
A： 涂色，剧情任务，救火……

Q： **听说这个回收周期很长很长……**  
A： 说明排序这个玩法机制长留比较优秀。除了水排序，还可以做其他排序，换主题不影响长留。

Q：**倒水足够解压，能不能保留倒水的解压感，换个玩法呢？**  
Q：**还有没有其他解压的新玩法呢？**

## 融合创新深度重考

有了上面的脑暴，我们已经记录了一些思路。让我们用排列组合的方式完善这些思路，进行创新思考。

### 主题/玩具

除了倒水，还有哪些主题可以进行选择？

- 螺母，小球，沙子，毛线，硬币...
- 螺母，小球这些主题，看起来 ASMR 爽感反馈不足。
- 沙子，毛线，硬币，这些似乎有些爽感反馈。

### 视角

爆量素材是3D视角，产品从 2D 表现转向 3D 表现，有没有机会？

### 控制方式

- 点击控制改为拖拽控制是可行的吗？
- 点击排序变为Auto Sort自动排序是不是更顺畅呢？
- 排序每一步都需要点击选择，操作上好烦。自动排序能不能更吸引泛用户？

### 机制融合

1. 水排序 + 涂色（局内目标）
2. 水排序 + 救救小姐姐（剧情任务目标）
3. 倒水 + Screw Jam + 涂色
4. 倒水 + Auto Sort
5. ...

| 主题 | 水，试管 | 沙子，毛线，硬币 |
| --- | --- | --- |
| **机制** | 水排序 | +局内目标 |
| **爽感** | 倒水 |  |
| **控制方式** | 点击 | 拖拽 |
| **视角** | 2D | 3D |
| **规则** | 点击排序 | 自动排序 |

## 更深入的思考和讨论

一路思考下来，目前比较倾向的测试方式是：**涂色（局内目标）+ 倒水 + Auto Sort** ，理由如下：

1. 涂色，提供了更好的局内渐进进度目标感，这点有助于变现转化以及关卡留存。
2. Auto Sort，简化了水牌序每一步都需要点击选择的体验。
