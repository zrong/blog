目前有两种主要的方法，可以让微信直接和 OpenClaw 通信。

但你们不要想多了。让微信官方的机器人，做到和飞书中的机器人一样，在群里作为小助手回复信息，**是不可能的。**

**它只能作为你的私聊对象。**

<!--more-->

## 接入已有的 OpenClaw 实例

要确保手机上的微信是最新版本。

- 对于 iOS 手机，升级到最新的 `8.0.70`。
- 对于 Android 手机，如果已经是 `8.0.69`，建议访问官方网站下载安装包，再更新一次：

<https://weixin.qq.com>

![微信版本 8.0.69](/uploads/2026/wechat-openclaw-access-1.jpg)


点击微信中的插件进行连接：

![点击微信插件进行链接](/uploads/2026/wechat-openclaw-access-2.png)

进入微信的 `我 -> 设置 -> 插件` 配置，找到 **微信 ClawBot** 插件。

![微信ClawBot插件](/uploads/2026/wechat-openclaw-access-3.jpg)


这里的体验其实很不好，它直接给了一段命令让你执行：

```bash
npx -y @tencent-weixin/openclaw-weixin-cli@latest install
```

这段代码，必须在安装了 OpenClaw 的机器上 **手动执行，不能让龙虾代为执行。**

因为安装后会出现一个二维码。如果让龙虾代为执行，这个码你就没法看到。

![安装流程](/uploads/2026/wechat-openclaw-access-4.png)


在插件界面中点击扫码，扫码二维码进行连接。

连接成功后，微信的聊天列表中会出现一个名为 **微信ClawBot** 的联系人。这个联系人可以置顶，但不能被拉入群聊。

![微信ClawBot在聊天列表中独立出现](/uploads/2026/wechat-openclaw-access-5.png)

这有点像那个啥也干不了的元宝，但好处是 **微信 ClawBot** 机器人能直接识别语音指令：

![啥也干不了的元宝.mm.jpg](/uploads/2026/wechat-openclaw-access-6.jpg)


## 接入QClaw

对于懒得折腾的同学，可以直接安装 `QClaw v0.1.16` 以上的版本。

因为这个版本可以直接使用上面刚刚推出的 **微信 ClawBot**。在上个版本里，QClaw 还需要通过客服会话才能进行通信。

但坏处是，一个微信只能连接一个龙虾。如果你连接了 OpenClaw，再跑来连接 QClaw，那么之前的 OpenClaw 就断联了。

建议目前还 **没有折腾本地龙虾** 的同学，可以安装 QClaw 试试。这是当前成本和效率都比较平衡的方案了。每天 4000 万 Token，至少能聊天 120～200 次了。

<https://qclaw.qq.com/>
