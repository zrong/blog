## 三个不确定

但这里有三个不确定性：

1. 视频平台不确定。
2. 刷视频的时间不确定。
3. 刷视频的设备不确定。

比如，曾老师日常用抖音学（mo）习（yu），在微信视频号研（mo）究（yu），在 B 站看（xue）片（xi）。

曾老师用安卓手机刷抖音，在 Windows 上的微信里看视频号，在 macOS 的 Edge 浏览器里看 B 站。

看到一个好视频，随手收藏。下次想找时，却不知道当时手滑收藏到了哪里。

即使想起来，也可能因为视频下架、作者被封号等原因而无法查看。

因为阅片无数，曾老师开发了一个用来保存看过视频的 Skill。很简单，把视频链接直接发给它，就能自动下载并上传到视频仓库。

![曾老师的创意视频仓库](/uploads/2026/excellent-video-save-skill-1.png)

## 牛百万的能力

曾老师的 Agent 助手叫牛百万。日常看到好视频，只需要把视频链接丢给它，就能自动完成下载。

同时支持抖音、微信视频号和 B 站的视频下载。

当然，YouTube、今日头条、爱奇艺等常见视频网站也都支持，甚至 P 站也没问题。

![牛百万抖音/微信视频号/B 站](/uploads/2026/excellent-video-save-skill-2.png)

只需要告诉牛百万：

> 帮我下载「链接」并上传到视频库

对于上面的用法，需要安装两个 Skill：`video-downloader` 和 `immich`。

任何 Agent 都可以使用，`OpenClaw`、`Hermes Agent`、`Codex`、`Claude Code`、`WorkBuddy` 和 `TraeWork` 都没问题。

## video-downloader

以上文提到的抖音、微信视频号和 B 站为例，使用的下载方式并不相同。

其中，抖音和微信视频号必须先在运行 Agent 的设备上登录一次。

安装时，可以直接告诉 Agent：

```text
帮我安装下面的 skill 并做好后端配置：

https://github.com/zrong/skills/tree/main/video-downloader
```

你的 Agent 会自动打开浏览器，请你扫码；扫码成功后，浏览器会自动关闭。

视频会自动下载到 `~/Downloads/video-downloads/[账号]/视频文件`。

## 视频上传

如果视频不需要进一步整理和查看，那么做到上一步即可。

但如果希望有一个方便随时查看和共享的视频库，就可以继续往下看。

曾老师推荐用 Immich 做视频库：https://immich.app/

部署在自己的 NAS 上，简直不要太开心，百度网盘看了沉默，iCloud 见了流泪。

曾老师写了一个 `immich` Skill，支持上传视频。只要配置好 API key 和自部署实例的网址，就能使用。

```text
帮我安装下面的 skill 并做好后端配置：

https://github.com/zrong/skills/tree/main/immich
```

接下来可以和 Agent 说：

> 帮我下载「链接」并上传到 `immich`
