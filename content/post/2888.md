曾老师昨天买了小米的 Xiaomi MMO Token Plan（100 元档），改了两个 BUG 就剩 80 块了……

![小米 Token Plan 套餐用量](/uploads/2026/llm-api-slow-afternoon-1.jpg)

问题是，这还卡着，一个问题改 40 分钟没改完。

曾老师这是第一次希望 token 快点花完，因为 token 不动，证明模型被限流了。

![eb4cb83a851817a9beb3f3b8c0454781.png](/uploads/2026/llm-api-slow-afternoon-2.jpg)

小米的 `mimo-v2-pro` 编程能力还是不错的，曾老师觉得差不多达到了 `GLM 5.1` 的水准。当然有可能是 GLM 5.1 太卡，水准发挥不正常？

一到下午，对于我这种每个模型都开一个窗口，同时干活的人来说，也无法逃过被卡住的命运，因为：

**所！有！模！型！都！卡！！！**

智谱的 GLM 5.1 超卖就不说了，一到下午就 429。

![智谱的超卖](/uploads/2026/llm-api-slow-afternoon-3.jpg)

速度发挥最稳定的莫过于 MiniMax-M2.7（官方 Coding Plan），贼快贼快的，虽然有时候不太聪明：

![MiniMax-M2.7 整理发票](/uploads/2026/llm-api-slow-afternoon-4.jpg)

火山方舟 Coding Plan 中的 `Kimi-k2.5` 慢到没法用！有网友说可能在整个池子里有人传图吧。

![Kimi k2.5 传图导致 TTFT 有影响](/uploads/2026/llm-api-slow-afternoon-5.jpg)

那么，这么多模型一起用，到底哪个编程能力更强点呢？分三个层次吧：

- 在不卡的情况下，自然是 Claude Opus 4.6 断层领先。
- GLM 5.1 和 Mimo v2 Pro 大约在一个级别。Gemini 3.1 也差不多在这个级别。
- MiniMax M2.7 和 Kimi k2.5 稍弱。

这只是每个模型都烧了十几亿 Token 之后的一个整体体验，曾老师不对上面的排行结果负责。

最近曾老师的更新可能不太正常。没办法，每天和 AI 缠斗太久，被蒸馏了不少技能。

愿世界和平，愿模型不卡，愿霍尔木兹海峡早日重新开放。

![愿世界和平](/uploads/2026/llm-api-slow-afternoon-6.jpg)
