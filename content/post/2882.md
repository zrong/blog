## 惨不忍睹的提示词

下面这段提示词，也是许多 AI 账号教大家使用的提示词，是无法生成合格视频的。

```
完全对标参考 @视频1，运镜、景别、背景音乐卡点节奏，C 位男主 @图像1 一比一复刻原视频中心男主全部舞蹈动作，周边伴舞换成 @图像2 @图像3 @图像4 @图像5 @图像6 同步匹配视频伴舞动作站位；场景使用 @图像7 的末日废土风格，动作丝滑，运镜顺滑稳定，好莱坞歌舞动作大片质感，动态流畅度拉满。
```

下面简单讲讲，使用 Seedance 进行视频重制时的提示词技巧。

## 最容易出现的错误

以下几个情况最容易出现：

- 结果视频中出现了重复的人物。
- 结果视频中出现了参考视频的背景。
- 结果视频中出现了错误的人物服装和样貌（张冠李戴）。
- 结果视频中出现了肢体融合与换脸的情况。

## 解决人物重复和肢体融合问题

![点烟](/uploads/2026/polska-jumpstyle-ai-video-reference-prompt-5.png)

### 锚定伴舞位置

原提示词中「周边伴舞换成……」会让 AI 在画面边缘随机生成人物。解决方案就是强调参考人物的位置：强制规定「左前、左后、右前、右后」，这能极大降低 AI 在同一个位置生成两个 @图像2 的概率。

### 处理高危动作

目标视频「众人挤上来点烟」这个动作，很容易导致「肢体融合」和「克隆脸」。通过强调 **呈半包围状** 和 **身体轮廓独立**，可以引导模型在生成时保留人物的 Z 轴深度（前后距离），减少画面平面化导致的粘连。

### 强化物理遮挡

为了防止人物和椅子前后重叠错误（穿模），直接在提示词中告诉大模型「明确物理遮挡关系」。

### 服饰颜色区隔

如果抽卡多次依然出现人物重复，可以给 @图像1 到 @图像5 分别加上非常简短的服饰颜色描述（例如：@图像1 穿黑皮夹克，@图像2 穿红背心……）。AI 对颜色的隔离非常敏感，这能强行将 5 个角色的潜在空间分开，终结克隆人现象。

### 优化后的提示词

```
## 全局风格与角色设定

完全对标参考 @视频1 的运镜、景别与背景音乐卡点节奏。场景设定为史诗级末日废土风格（Epic doomsday wasteland style），废弃的背景，光影对比强烈。画面中严格限制仅有 5 名独立且唯一的角色。

C 位男主 @图像1 1:1 复刻原视频中心男主的全部舞蹈动作。

4 名伴舞各自锁定独立站位：左前 @图像2、左后 @图像3、右前 @图像4、右后 @图像5。伴舞同步匹配原视频的伴舞动作。

动作丝滑，运镜顺滑稳定，具备好莱坞歌舞动作大片质感，动态流畅度拉满。

## 分镜动作描述

**0～3 秒 | 全景转中景**

C 位男主 @图像1 嘴里叼着香烟，张开双臂，从画面后方的椅子处，向前跨步移动并稳稳坐在椅子上，随后做出掏香烟的动作。香烟始终固定在嘴上。明确人物与椅子的前后景物理遮挡关系，确保边缘清晰，无任何穿模。

**3～6 秒 | 贴身近景**

运镜拉近，4 名伴舞（@图像2、@图像3、@图像4、@图像5）从画面四周的固定站位向画面中心靠拢，呈半包围状给坐在中间的 @图像1 点烟。每个人物面部特征分明，身体轮廓独立，不发生肢体融合。

**6～9 秒 | 近景特写转中景**

@图像1 动作利落地推开所有人伸过来的手，从椅子上迅速起身，左手手臂笔直探出，食指清晰地指向画面左侧。伴舞随之向后散开，画面中保持 5 人各自的原始特征，无任何新增角色。
```

## 解决群舞的控制问题

![群舞](/uploads/2026/polska-jumpstyle-ai-video-reference-prompt-6.png)

视频第二段群舞场景加入了特定的背景图（@图像6）、两组不同类型的伴舞（指定人物 @图像2～5，以及群像丧尸 @图像7），非常容易出现 **丧尸和主角长得一样、特定伴舞被同化成丧尸，或者背景图与人物空间透视错乱** 的问题。

为了解决这些问题，我们需要在提示词中建立严格的 **同心圆站位法则**，对舞者的空间进行隔离，明确区分 C 位、内圈伴舞和外围绕场伴舞。

![群舞参考图和提示词](/uploads/2026/polska-jumpstyle-ai-video-reference-prompt-7.png)

### 使用同心圆站位建立隔离带

AI 很容易把 @图像7 的丧尸元素「传染」给 @图像2～5。在提示词中，使用「第一层、第二层、第三层」以及「内圈 / 外围」这样的空间量词。这种描述能强迫模型画出「结界」，防止特定角色被丧尸化。

### 强调特征保持

群舞时，AI 为了省算力，经常会统一所有人的服装或脸型。强调 **保持各自的面部与服装特征**，就是为了抵抗 AI 的「偷懒」机制。

### 背景图的融合提示

这里指定了 @图像6 作为场景，AI 有时会把背景当成一张纸贴在人物后面（失去景深），有时还会频繁切换原始背景与参考背景。

加入 **建立准确的三维空间透视**，让 AI 理解这是一个有深度的舞台，并持续强调新的参考背景，就能解决这个问题。

### 优化后的提示词

```
## 场景与整体画面设定

舞蹈场景严格使用 @图像6 作为环境底图，死死锁定在 @图像6 的末日废土钢铁风格，保持准确的三维空间透视不变，完美对齐 @视频1 中的人物空间落位。

完全对标参考 @视频1 的运镜轨迹、景别切换与背景音乐卡点节奏。好莱坞歌舞动作大片质感，电影级光影，运镜顺滑稳定，动态流畅度拉满，动作丝滑无拖影。

## 角色严格分区与站位锁定

画面采用严格的三层空间站位分布，角色位置绝对锁定，互不干扰，绝不互换位置，绝无重复人物：

- 第一层（中心 C 位）：男主 @图像1 独占画面绝对中心。
- 第二层（内圈核心伴舞）：4 名特定角色 @图像2、@图像3、@图像4、@图像5 环绕 C 位，各自死死锁定原视频中核心伴舞的四个独立站位（左前、右前、左后、右后）。每个人物在画面中仅出现一次，保持各自的面部与服装特征，绝不重复。
- 第三层（外围群舞）：更多外围与背景处的舞伴，全部替换为 @图像7 中的丧尸群。丧尸群严格限制在画面外围，绝不侵入第二层的核心伴舞区。

## 动作与舞蹈复刻

- 所有舞蹈动作 1:1 精准复刻 @视频1。
- 中心男主 @图像1 完美还原原中心男主的全部高难度舞蹈动作。
- 内圈伴舞（@图像2～5）与外围丧尸群（@图像7）同步匹配原视频对应位置伴舞的动作与节拍。群舞动作整齐划一，没有穿模与肢体打结。
```
