今天非常荣幸站在这里和各位聊聊当下大家最关注的赛道：小游戏。如今小游戏竞争激烈，买量成本也持续上涨，我们在小游戏赛道中怎么找到确定性？星辉的答案是，IP 提供了确定性的流量，而品类的融合加减法决定产品的生命周期。

今天由我分享的主题是，从《冒险岛》到小游戏 IP + 的兼容加减法。接下来 20 分钟，我将以星辉游戏在《冒险岛》IP 上的实战复盘为例，跟大家一起聊聊我们怎么在小游戏市场里切出属于我们自己的增量。

先跟大家介绍星辉游戏。星辉游戏始终坚守研运一体，在品类布局上，我们深耕 SLG、放置两大高潜力、长生命周期的赛道。对我们来讲，IP 不仅是发行的买量素材，还是产品研发的底层逻辑，所以我们深度挖掘了 IP 的内核魅力，把 IP 的情感价值贯穿到研发和发行的全流程。

可以看到，星辉旗下拥有包括《冒险岛》《盗墓笔记》等头部 IP。特别需要强调的是，星辉作为《冒险岛》IP 在中国的合作伙伴，未来将更加聚焦经典 IP。我们依托小游戏的生态优势，进行更精细化的优质内容打磨，通过不断的产品迭代升级，沉淀更大的用户规模，构筑更长线的游戏生态。

![改编策略：协同 IP 做增量](/uploads/2026/maple-story-ip-minigame-compatible-design-2.png)

这首熟悉的 BGM，在座有不少伙伴瞬间被勾起青春的回忆。我们进入到《冒险岛》的 IP 理解与改编策略，这也是星辉精品化长线运营的关键。面对这样一个跨越 20 年的顶级 IP，我们的核心策略就是协同 IP 做增量。这首 BGM 就是我们洞察 IP 用户的起点。

作为 2004 年现象级的端游，《冒险岛》凭借可爱的美术画风、职业系统和强社交属性，在当年吸引了非常多 70 后、80 后到 90 后的用户。到了今天，这部分核心受众的年龄推演已经来到 30 到 40+ 岁，他们每天被家庭和事业填满，整个娱乐时间呈现出高度碎片化的特征。在我们前代产品《冒险岛：联盟的意志》的玩家访谈中，超过一半的玩家反馈给我们：他们的生活节奏无法回去，但心中对《冒险岛》的情怀还是滚烫的，只要这首 BGM 响起，他们就想回去。

在这里，就产生了非常巨大的市场供需错位。用户在当下人生阶段，迫切希望有一款体验上更轻量、更轻松的《冒险岛》，让他们以更低的成本、无压力地回归到���初的冒险。顺着这样的洞察，我们发现，这批有情怀、缺时间的 IP 流失用户，跟微信小游戏用户特征存在着非常高的共性和天然的重叠。我们的思考就变成了：如何将 IP 情怀和小游戏生态做交集？什么样的方式能完美承接这两波用户？

![还原用户新阶段](/uploads/2026/maple-story-ip-minigame-compatible-design-3.png)

可以看一下 IP 用户喜欢什么，例如职业转职仪式感、经典怪物、经典场景，以及原汁原味的熟悉 BGM。《冒险岛》经典的视觉、视听表现，对用户来讲需要 100% 原汁原味地保留，这是他们想回到《冒险岛》的情怀底线。

我们再看小游戏用户，他们目前追求的是什么？小游戏用户本身追求的是短平快的及时反馈。《冒险岛》原本就有职业转职体验，天然匹配了小游戏用户对成长养成和收集解锁的核心偏好。因此我们融合了端游老玩家的情怀诉求和微信生态的用户特征，找准这两者之间的共同点，所以有了今天《冒险岛：枫之新篇》的立项。

在整个《冒险岛：枫之新篇》的立项和产品调优策略上，我们内部团队还是遵循了两个底层逻辑。第一个，是产品内核契合度，以及前端流量的市占率。在产品端，是玩法循环的深度契合。例如《冒险岛》最经典的玩法核心循环：先选职业、刷怪升级、获得装备，然后成长。这一循环和市场上经过充分验证的开箱 like 循环，在底层逻辑上是完全契合的。

第二，是平台流量池的考量。小游戏市场正在持续爆发，其中放置赛道在小游戏市场稳居高位，无论是新品活跃度，还是头部产品的吸金能力都非常强，整个大盘处于持续增长的态势。更重要的是，这种高认知 IP 在小游戏买量市场上具备降维打击的竞争力。基于我们的深度考量，最终我们选定了和 IP 内核高度适配、且有成熟市场验证的开箱 like + RPG 框架，重点瞄准微信小游戏的全域用户。

![产品与流量的双逻辑](/uploads/2026/maple-story-ip-minigame-compatible-design-4.png)

选定一个框架之后，接下来进入产品打磨和调优阶段。我们做这样的适配兼容加减法，首先是加法的兼容：如何用 IP 去激活玩法。在常规的开箱 like 玩法里，流派更多侧重机制，更多还是取决于玩家抽到装备的随机属性。为了把《冒险岛》最核心的转职体系还原回去，我们做了一套创新的加法，将经典的转职体系和开箱 like 流派构筑进行更深度的结构绑定。

以我们现在《冒险岛》经典职业黑骑士为例，玩家每一次转职都会获得特定的属性加成，比如黑骑士的技能直接锁定。这样一来，玩家在开箱时的流派选择和装备选择会变得更清晰。这一加法带来了双赢的效果。对于 IP 老玩家来讲，他们本身对职业体系非常熟悉，可以无缝理解并代入到流派构筑。对于非 IP 用户来讲，已经明确的流派天然降低了开箱玩法的理解门槛，这样他们可以更爽快、更自然地融入到《冒险岛》的生态。

![情怀的交集](/uploads/2026/maple-story-ip-minigame-compatible-design-5.png)

有了加法后，我们也会有减法。小游戏更强调高效率体验，所以我们在多维度上进行了更轻量化的减法兼容。第一个，是视觉和载体上的减法。我们抛弃了原版的横版大地图，选取了更符合小游戏用户单手操作习惯的竖版形态。通过微信轻量体验，降低流失老玩家回归《冒险岛》的时间门槛和心理门槛。第二，是养成深度的减法。传统 MMO 养成是复杂的，所以我们做了一刀切的精简，保留用户更关注的职业和装备养成线，让整个成长目标更清晰。第三，是付费和长期目标上的减法。在常规开箱游戏里，用户更多还是打造一套装备，然后这套装备会出现保值期比较短，甚至迭代比较快的情况，很容易造成用户后期的付费负担和流失。

所以我们在产品中后期增加了一个分身玩法系统，分身可以穿戴装备，从而获得额外提升。这里可以让中后期玩家有更明确、更长期的追求目标，也能降低装备的付费门槛，大幅优化玩家长期的付费体验。

![稳定的用户盘子](/uploads/2026/maple-story-ip-minigame-compatible-design-6.png)

除了核心养成，休闲小游戏也是《冒险岛：枫之新篇》在产品打磨过程中极具情怀标签的重要板块。玩过《冒险岛》的伙伴都知道，《冒险岛》不仅是一款 MMO，也是一个非常庞大的虚拟游乐场，有太多让这几代玩家刻骨铭心的肌肉记忆，这些机制天然带着休闲和社交属性。因此，在整个项目初期，我们将这些经典休闲玩法和随机事件作为更核心的入口植入到游戏。这既能完美还原端游的轻松氛围，也能更快速地提升泛用户转化和留存，同时兼顾这两部分用户的体验需求。

在产品持续调优的过程中，我们推翻了以往把休闲玩法只当作前端买量入口的粗暴套路，做了更深度的减法兼容。也就是将这些休闲玩法从单纯的前端流量入口，升级调优到深度融入游戏生态的核心循环。然后我们再不断优化经典玩法的体验节奏，融入减负机制和核心资源产出，让玩家在解压、回味情怀的同时，能更高效、更顺利地代入到游戏核心循环中。这种体验的减法，让整个游戏的内容生态变得更轻盈、更减压，真正契合微信小游戏随玩随停的平台定位。

成熟的产品打磨是基础。想要实现长线运营，必须延伸运营链路。在这方面，我们借助微信小游戏平台强大的能力，实现从用户触达到平台沉淀，再到长效留存的全域闭环。微信游戏板块针对我们这样正版授权的头部 IP，提供了非常宝贵的 IP 分类流量入口，让我们的产品在初期就能实现更高密度的曝光。

非常感谢微信平台提供了游戏圈这个阵地。游戏圈能更便捷、更及时地把长线内容，包括版本规划同步给玩家。除此之外，我们也发现，小游戏生态内的玩家有极强的自主活跃度。他们日常会在游戏圈内频繁分享体验日常、更新攻略，以及交流流派职业，甚至给我们提供非常有价值的产品优化建议。

我们在提取大盘数据后，得到了让我们非常振奋的结论：深度活跃在游戏圈的用户，在游戏内的七日留存能超过 80%，整个社区生态也变得更稳固，并且成为我们产品稳固长线的留存壁垒。得益于现在的产品加减法死磕，以及微信小游戏平台能力的加持，《冒险岛：枫之新篇》在近期也交出了一份比我们预期更健康的生态数据。

数据也证明了我们策略的可行性。也就是我们在稳固住《冒险岛》硬核 IP 基本盘的同时，也抓住了 IP 新一代用户，增速非常可观。从周同比、环比的留存和活跃曲线来看，泛用户正在呈现一个持续且健康的攀升趋势。让我们更欣慰的是，泛用户规模在持续放大，产品留存依然能保持稳中有涨。这里不仅验证了小游戏用户对我们 IP + 开箱放置模式的认可，也给了《冒险岛》在后续长线版本迭代、内容运营上更大的底气和信心。

总结星辉游戏踩过的坑，我们也沉淀了《冒险岛》IP 改编的经验。我们认为，当下长线小游戏 IP 的改编，必须围绕 IP + 平台 + 产品的三位一体策略。一是在 IP 层面，必须对用户阶段性的需求做更深刻的洞察，找准情怀的落脚点。二是在平台层面，结合微信小游戏超级流量池，必须用精细化的运营工具，同时兼顾泛用户破圈，以及流失 IP 老用户的精准唤醒。三是在产品层面，必须具备 IP 情怀之外的品类包容性，可以用加法构筑壁垒，用减法兼容大众。同时在体验细节上做更长期的版本迭代和打磨，这也是星辉游戏接下来在小游戏赛道中会持续验证完善的核心打法。
