## 时间线：2 个月的拉扯

下面是该事件的基础时间线。

| 2025 | 事件 | 主要参与方 | 财务价值 /<br>关键条款 | 战略结果 |
|---|---|---|---|---|
| 5月 | OpenAI 提出收购要约 | OpenAI, Winsurf | 约 30 亿美元的全资收购 | OpenAI 意图通过收购来增强其在开发者工具市场的竞争力。 |
| 6月初 | Anthropic 撤销 API 访问权限 | Anthropic, Winsurf | 不适用 | Anthropic 为防止其模型数据被竞争对手 OpenAI 获取而采取的防御性措施。 |
| 7月初 | OpenAI 收购交易失败 | OpenAI, Microsoft, Winsurf | 交易告吹 | 微软行使否决权，阻止了此次收购，以保护其 GitHub Copilot 业务。 |
| 7月11-12日 | 谷歌实施「反向收购」 | Google, Winsurf 核心团队 | 约 24 亿美元 (人才+技术许可) | 谷歌获得顶尖人才和技术，加强了其在代理式编程领域的实力。 |
| 7月14日 | Cognition 收购 Winsurf 剩余业务 | Cognition, Winsurf | 未披露 | Cognition 获得成熟产品、客户和团队，成为 AI 开发工具市场的新兴巨头。 |

## 细节：赢家、输家与格局变迁

Winsurf 的年度经常性收入 (ARR) 从 2024 年底的 1200 万美元，到 2025 年 2 月增至 4000 万美元，当前已达 8200 万美元，并拥有超过 350 家企业客户，100 万活跃开发者。

**OpenAI 的 30 亿美元收购要约**

2025 年 5 月，OpenAI 进入排他性谈判阶段，计划以约 30 亿美元的价格收购 Winsurf 。双方已经签署意向书，一度接近正式宣布。

OpenAI 并非具有完全的战略自由。尽管在 CEO 被赶下台事件中，微软站在了奥尔特曼这边，但 GPT-5 的强大压力，Meta 近期的挖人风波，都让 OpenAI 的竞争地位岌岌可危。

**Authropic 筑起高墙**

收购消息传出不久，Authropic 统治 Winsurf，将在一周时间内切断其对 Claude 3.x 模型几乎所有直接的 API 访问权限。此举被认为是对 OpenAI 的狙击。

尽管 Anthropic 保护了其知识产权免受 OpenAI 的威胁，但它也将其在一个主要平台上的大部分开发者用户群拱手让给了另一个竞争对手——Google，后者的 Gemini 模型立即被 Winsurf 作为替代方案进行推广 。这可以说是在一场战役中取得了战术性胜利，但在更广泛的战争中可能要付出战略性代价。

**捍卫者微软**

微软利用其与 OpenAI 之间复杂而强大的合作关系否决了这笔收购，清晰地表明了其自身的核心商业利益。微软将 Winsurf 视为 Visual Studio Code 和 GitHub Copilot 的直接竞争对手。此前，微软也曾批准 OpenAI 收购 AI 硬件初创公司 IO，因为微软在该领域没有竞争利益。

微软的行动表明，其与 OpenAI 的合作关系是有条件的，当合作伙伴的战略举动与其自身核心利益冲突时，它会毫不犹豫地出手组织。此举强化了其开发者工具的战略。通过阻止 OpenAI 拥有一个与之竞争的 IDE，微软将开发者更牢固地锁定在微软/GitHub 的生态系统内。

**机会主义掠食者 Google**

几乎在 OpenAI 交易失败的同时，2025 年 7 月 11 日至 12 日，Google 宣布已聘请 Winsurf 的 CEO Varun Mohan、联合创始人 Douglas Chen 以及一个精选的顶尖研发团队加入其 DeepMind 部门 。

谷歌为此支付了约 24 亿美元，但这笔资金并非用于购买公司，而是用于获取 Winsurf 部分技术的非排他性许可，以及支付被聘用团队的薪酬。这种策略使科技巨头能够迅速获取关键资产，同时有效规避反垄断审查。

Google 充分利用了微软否决所造成的混乱局面，执行了一次完美的「反向收购」，在没有承担完全收购的成本和监管摩擦的情况下，获得了 Winsurf 的核心价值——顶尖人才和关键技术，迅速加速其 Gemini 模型成为 GitHub Copilot 真正竞争对手的进程 。谷歌不仅增强了自身实力，还通过夺走其主要竞争对手 OpenAI 的目标猎物，积极地削弱了对方，这是一次重大的战略妙手。

**最终的受益者 Cognition**

2025 年 7 月 14 日，就在谷歌宣布消息几天后，Cognition 宣布已签署最终协议，收购 Winsurf 的全部剩余实体 。Cognition 的 CEO Scott Wu 也提到，这是疯狂的 72 小时，周五电话沟通，周一敲定，周二宣布。

交易结构对留下的 Winsurf 员工极为有利，包括 100% 的员工将从交易中获得经济利益、免除所有既有期权的「悬崖期」 (vesting cliffs)，并对已完成的工作完全加速兑现。此举旨在留住至关重要的人才 。

**被肢解的 Winsurf**

在 Google 进行「反向收购」后，Winsurf 失去了其创始领导层。业务负责人 Jeff Wang 被任命为临时 CEO，负责管理剩余的约 250 名员工和企业业务 。

这是个苦乐参半的解决。虽然创始人和核心研发人才通过谷歌的交易获得了丰厚的回报，留下的员工也得到了 Cognition 的优待，但这个独立的公司及其独特的愿景最终被行业巨头们肢解和吸收。

## 曾老师感受：技术、 食物链、速度、等级

氛围编程的发展有三个阶段：

- 第一阶段：自动补全 (例如 IntelliSense)
- 第二阶段：AI 建议 (例如 GitHub Copilot 的早期版本)
- 第三阶段：AI 代理 (例如 Winsurf 的 Cascade、Cognition 的 Devin) —— 在此阶段，AI 成为开发过程中一个主动、自主的参与者。

这一系列事件完美地展示了 AI 产业的「食物链」效应。基础模型提供商（微软、谷歌、Anthropic）位于食物链顶端，制定规则。应用层（Winsurf）是宝贵的猎物。而敏捷的捕食者（Cognition）通过收拾残局而茁壮成长。价值（人才、IP、客户）从应用层（Winsurf）向上流向平台/巨头层（谷歌），并横向流向一个定位精准的竞争对手（Cognition）。这揭示了 AI 市场中清晰的权力等级结构。

从公司经营的角度，示了一个清晰的因果链条。OpenAI 的收购要约触发了 Anthropic 的防御性壁垒。而该交易的潜在成功又迫使微软出手干预，导致了否决。微软的否决在 Winsurf 内部造成了战略方向的真空，谷歌立即填补了这一空缺，出手获得 Winsurf 创始人。最终，这个失去领导但资产丰厚的公司，成为了像 Cognition 这样行动迅速的竞争对手眼中完美且可能被低估的收购目标。每一步都是前一步的直接或间接后果，生动地展示了 AI 市场中超乎寻常的竞争性和反应速度。

Winsurf 事件标志着人才争夺战的升级，从传统的人才收购演变为更具攻击性的、外科手术式的「反向收购」或战略性肢解。科技巨头现在愿意为了获得其想要的特定资产而将一家公司分拆，而将其余部分抛之脑后 。对于初创公司而言，这意味着其领导团队本身就是一项可被单独攫取的资产，这构成了一个重大的脆弱点 。

近期 AI 行业事件不断，Meta 的小扎亲自下场过亿美金年薪挖人，Manus 裁员清空社交媒体远赴新加坡，月之暗面开源 K2 模型引爆互联网……这展示了 AI 行业的快速发展，也不断警醒着我们，远离泡沫，持续修炼内功，跟进行业发展，用 AI 能力持续嵌入自己的工作流。
