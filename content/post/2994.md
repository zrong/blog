自从腾讯广告推出 **新广告投放（3.0）**以来，业内就一直有着持续热烈讨论。而在投放工作是重中之重的小游戏行业， 不少游戏厂商尝到了 3.0 大幅提升人效的甜头，也有厂商仍在苦苦摸索 3.0 的使用技巧。当竞争进入深水区，买量成本居高不下，怎样实现投放工作的精细运营？在去年12月开展的游戏生态峰会上，腾讯广告提出了「技术生态」作为底层支撑的答案，新广告投放（3.0）落地在小游戏行业，逐渐形成了一张全生命周期方法论的小游戏营销全景图，为各位深水区玩家点亮了一盏灯塔。

本文试图基于腾讯广告近期推出的 **小游戏营销全景图** ，对新广告投放（3.0） 的痛点和解决方案做一些探讨。

## 1. 小游戏行业投放变革早已到来，痛点和爽点齐飞

在2010年前，数字广告处于 **1.0 时代**。 彼时投手的主要工作是在 Excel 表中为甲方爸爸们手动选择广告位、制作素材、调整大小、上传，俗称「爬格子」。从2013年起，计算广告慢慢取代了爬格子模式，**这就是 2.0 时代**。 在 2.0 时代， 机器学习强调基于受众标签的自动化匹配，广告投放变得灵活精准，也催生了广告投放技术解决方案的中间商和「广告投放优化师」岗位。（胡扯游戏也撰写过类似的主题：[计算广告](https://mp.weixin.qq.com/mp/appmsgalbum?__biz=MzA5NzQ3NDM3MA==&action=getalbum&album_id=1800592475711946758&scene=21#wechat_redirect "https://mp.weixin.qq.com/mp/appmsgalbum?__biz=MzA5NzQ3NDM3MA==&action=getalbum&album_id=1800592475711946758&scene=21#wechat_redirect")）

但是，基于计算广告系统的 2.0 时代，优化师常常被「堆基建」和投放效果「玄学」的问题困扰，随着2023年AI大模型的爆发式增长，**新广告投放（3.0）** 应运而生，基于通用人工智能（AGI）的大模型，实现广告系统对生意的真正理解，这也要求各位厂商和优化师调整自己的投放思路，将核心工作转变为做好创意和确定投放情景。整体工作思路的转变，在一定时期内，一定会给各位带来既有爽点，也有痛点的投放状况。这一点从曾老师身边的案例也可窥见一斑。

### 小游戏营销的投放痛点和解决方案

大家吐槽的主要有这么几点：**起量困难、放量期增长曲线不稳定、创意重复度高导致投放效果不佳。**

以上几个问题，在这里曾老师也给出一些解决方案供参考——

### 1）起量困难如何解决？适应3.0思路和善用相关工具

对于大家经常提到的新品初期没量的问题，需要首先定义需要的量级标准，其次要定义「没量」的周期。

对于量级，曾老师在 [首日ROI 0.03%！真实案例解读小游戏投放测试数据]({{< relref "post/3045.md" >}}) 一文中聊到过，在小游戏测试期，持续提供每日 500~1000 的新增，是很有必要的。

对于周期，优化师需要给计划更多的学习时间。新广告投放（3.0）对于新创意的观察期为 48~72小时。在观察期，若数据表现突出，就可以提供广告的预算以培养明星创意；若消耗持续低迷，就应该进行素材替换。

![](/uploads/2026/tencent-ads-3-0-boost-4.png)

其实，影响起量的因素十分复杂，除了创意产生的影响之外，**营销链路**的选择（营销链路：从广告投放到最终转化的过程）也十分重要，考验着优化师对用户的理解。这里有一张核心链路图可供大家参考，是腾讯广告近期根据消耗排名总结的18条全行业核心链路，如果你没有自己的营销链路方法论，可优先选择小游戏部分的这四条链路：

- 启动-注册-创建角色-完成新手指引-付费
- 启动-注册-广告变现
- 启动-注册-创建角色-完成新手指引-广告变现-付费
- 沉默唤起-付费

![](/uploads/2026/tencent-ads-3-0-boost-5.png)

### 2）放量期增长曲线波动如何解决？

**平推期** 出现量级波动，有这样两个主要的原因：

1. 有 50% 的问题是配置错误，这也是新手优化师的常见错误。
2. 有同行业，不同主体的客户在抢量。

尤其是在跑量期间，优化师需要非常谨慎地调整出价，避免频繁的变化影响算法。**要相信模型的力量。**

根据 3.0 系统的预拉取机制，下面的频繁调整对于跑量的影响较大：

1. 在投期间降价。
2. 窄定向的调整。
3. 降低预算，例如每天调整 4-5 次，或者进行 20-30% 的预算降低。

对于竞品抢量， 可以根据竞品特点和自身产品需求，思考这样几个问题：我方产品与竞品的上游客户一致程度有多少？如果提高出价，我方产品的 ROI 压力有多大？在素材制作方向上，我方与竞品的重合度有多少？

针对这些问题的答案，动态调整投放策略和素材方向，实时关注消耗变化和竞品投放趋势，做到有的放矢。

平台会优先展示新鲜度高的创意，创意重复度高则会受到跑量的挤压，也即创意的探索不充分，最终导致投放效果不佳。

![](/uploads/2026/tencent-ads-3-0-boost-7.png)

**AI 素材在 3.0 系统中有更高的支持度。** 能低成本甚至是零成本地实现大规模的素材制作；而组件化创意则是对创意进行充分地探索，提升创意的丰富度。

## 2. 理解小游戏营销的全生命周期

曾老师还在写程序那会儿，有次接入某大厂 Python SDK。一看源码，就知道这个写 SDK 的哥们是 Java 程序员，甚至没有看 Python 文档就乱写一气，给我好一顿吐槽：

2. 忍不住定义了几个 Interface；
3. 函数名和变量名贼长；
4. 不会使用列表推导式，填充 List 硬写 for 循环；
5. ……

**优秀的程序员，知道不同编程语言有自己的 Style 和最佳实践。**

那么，新广告投放（3.0），是不是也有自己的 Style？我们是否在用 2.0 的 Style 适配 3.0 的用法，才导致投放效果不尽如人意呢？

腾讯广告近期推出的 **小游戏营销全景图**，覆盖了小游戏在 **测试期、平推期、召回期** 的全部营销重点技巧。基于这张图，我们更容易理解新广告投放（3.0）的 Style。

![](/uploads/2026/tencent-ads-3-0-boost-9.jpg)

**测试期：探索高潜人群范围，提升冷启动率**

通过少量预算，稳定冷启动和达成效果，提高正式上线时的成功率。

**平推期：多产品组合高效拿量，丰富创意形式**

根据测试期反馈，以买新用户为主，制定最佳跑量策略，快速扩张用户数量，短时间内高效拿量并保持平稳投放。

**召回期：持续稳定拿量，召回流失用户，提升转化**

买新用户并挽回流失用户，延长游戏生命。

## 3. 坚实的底座支撑和丰富的产品矩阵，让营销有「技」可循

### 底层支撑——理解自身生意，洞察营销对象

关于前文群友聊到的 **起量困难** 问题，从 **测试期** 起，就可以通过「星盘」，快速学习品类标杆产品的投放。 通过在「投放指标分析」中基于同游戏类型所有产品的「洞察口径」分类，查看同类产品的消耗趋势和档位，确定起量策略。

![](/uploads/2026/tencent-ads-3-0-boost-10.png)

在 **平推期** 和 **召回期**，利用工具给出的同类产品的年龄和性别特点，拓展定向到更多推荐人群，实现更广泛的人群覆盖。

![](/uploads/2026/tencent-ads-3-0-boost-11.png)

持续放量期间，可基于版位、出价工具、出价策略等维度，尝试不同的优化目标组合，进一步精准调整。

![](/uploads/2026/tencent-ads-3-0-boost-12.png)

### 底层支撑——平台参与营销链路构建

**营销链路** ，是指一条广告的展示周期里，消费者从「看到广告」到「完成转化」的整个链路中，通常会有一系列操作行为，这些行为组成的路径就是「营销链路」。

新广告工具提供的营销链路能横贯小游戏全生命周期，提升模型预估效果、提升冷启动速度和成本达成效果、提升真实转化的 CVR。

![](/uploads/2026/tencent-ads-3-0-boost-13.png)

前文提到的量级波动，与全景图中提到的 建设数据生态 流程息息相关。曾老师曾经在 [强制回传？微信小游戏的新SDK方案解读]({{< relref "post/3029.md" >}}) 一文中介绍过全景图中的 小游戏 SDK 工具。

### 底层支撑——重视创意，巧用工具

大部分优化师都知道要将工作的重心转移到 「卷创意」上，但是除了依靠经验和对市场的嗅觉之外，创意产能的客观提升也是对优化师的一大考验。

小游戏营销全景图中的 **创意深耕** 部分，包含了 **组件化创意** 和 **腾讯广告妙思** 两大工具，致力于提升优化师的素材生产效率。在小游戏行业的全生命周期，创意产能的提升都具有非凡的意义，产量大了，爆量的概率自然也能得到提升。

组件化创意：提供了一次性输入多组视频/图片、多条文案、多个落地页进行创意创编，再由系统自动组合、优选创意投放的能力，为优化师的素材批量生产工作，提供了强大的效率引擎。

比如某小游戏客户，得益于组件化创意对创意组合的充分探索，有效地降低了创意重复度，促进了条均消耗贡献，提升了 ARPU。

![](/uploads/2026/tencent-ads-3-0-boost-17.png)

### 腾讯广告妙思：从腾讯广告出发的，商业内容AIGC制作与应用分发平台，能够快速创造广告/生意素材。提升投放效率，实现在3.0时代更好拿量。
